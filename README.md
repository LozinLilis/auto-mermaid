# auto-mermaid

![badges](./assets/badges.png)

Vague diagram requests — especially _"maintain the diagrams for my repo"_ — become a set of Mermaid diagrams grounded in real repository facts: auto-sliced scope, routed across **32 chart types**, rendered and validated before delivery.

## At a glance

- **Repository maintenance mode** — inventory the scope, slice it, pick the right chart type(s) per slice, generate `.mmd` sources, maintain a diagram atlas
- **Explicit-type mode** — your chosen chart types are honored, with fit checks and stated limits
- **Facts first** — every relation traces to source, docs, tests, or Git history; unknowns are marked, never invented
- **Render or stay silent** — no validation claims without a real `mmdc` render
- **One style authority** — `.auto-mermaid/theme.css` per repo; sources stay semantic
